# 像素塔防：遷徙之戰

以原生 JavaScript + Canvas 2D 撰寫的塔防遊戲（無遊戲引擎、無執行期相依套件），開發與打包使用 Vite。

## 特色

- **6 種基本塔**：箭塔、砲塔、冰霜塔、雷電塔、毒霧塔、狙擊塔，各有物理/魔法、對空/對地、範圍、緩速、連鎖、毒傷等特性。
- **升級**：每座塔可花金幣升到 Lv5。
- **合成**
  - 同種同星兩座塔 → 星等 +1（最高 ★★★★，每星傷害 ×1.8）。
  - 配方合成：兩座 ≥ ★★ 的不同塔 → 6 種特殊塔（風暴塔、瘟疫砲、鷹眼塔、電漿砲、寒毒塔、機槍塔）。
  - 可用「合成」按鈕，或直接把塔拖曳到另一座塔上。
- **每 20 波地圖變遷**：地形主題、路徑、障礙物與能量格全部重新產生；所有塔收進倉庫，可在新地圖上**免費重新部署**，另得遷移補助金。
- **能量格 ✦**：蓋在上面的塔傷害 +25%，地圖變遷後位置會改變。
- **9 種敵人**：小兵、疾行者、鐵甲兵（護甲）、蟲群、飛行獸（直線飛行）、分裂體、魔盾兵（魔抗）、治療師、每 10 波出現的魔王。
- 目標選擇（最前/最後/最強/最近）、1×/2×/3× 速度、暫停、自動開波、利息、三種難度、自動存檔（每波結束）、最佳紀錄、音效、快捷鍵、手機觸控。
- 撐過第 100 波即勝利，之後可繼續無盡模式。

## 指令

```bash
npm install       # 安裝 Vite
npm run dev       # 開發伺服器 http://localhost:3000
npm run build     # 打包到 dist/
npm run preview   # 預覽打包結果
npm test          # 單元測試（node:test）
npm run sim -- normal 8   # 無畫面 AI 模擬，檢查各難度平衡
```

## 操作

| 按鍵 | 功能 |
| --- | --- |
| `1`–`6` | 選擇要建造的塔 |
| 空白鍵 | 開始下一波 |
| `U` / `M` / `S` | 升級 / 合成 / 賣出選取的塔 |
| `T` | 切換目標模式 |
| `P` / `F` | 暫停 / 切換速度 |
| `H` | 說明 |
| `Esc`、右鍵 | 取消 |

## 專案結構

```
src/
  config/        平衡數據：塔、敵人、地圖主題、常數
  game/          遊戲邏輯（不依賴 DOM，可在 Node 中執行）
    Game.js      狀態、波次、戰鬥、合成、地圖變遷、存檔
    entities.js  Tower / Enemy
    maps.js      依 seed 程序產生地圖與路徑
    waves.js     波次與血量成長
    towerLogic.js 數值計算、升級費用、合成規則
    Renderer.js  Canvas 繪圖
    audio.js     WebAudio 合成音效
    storage.js   localStorage 存檔
  ui/            DOM 介面與輸入處理
tests/           node:test 單元測試
scripts/         平衡模擬腳本
```
